# 截图清单

README 里引用了下面这些截图。截好后用对应的文件名存进这个文件夹（`docs/images/`），README 里就会自动显示。

建议：先用 **⋯ → 🧪 Add 5 test replies** 加几条虚拟回复，画面会更丰富。Slack 用浅色主题截图，在 README 里更清楚。

| 文件名 | 截什么 |
|---|---|
| `slack-event.png` | 频道里的活动消息，最好已经有几个人回复（底部显示"✅ N replied"） |
| `slack-thread-reply.png` | 帖子里的对话：某人只说了"想吃披萨"，Gather @ 他追问时间 |
| `slack-confirm.png` | 回复后收到的"Got it! Here's what I understood"确认卡片 |
| `slack-dm-private.png` | 私聊 Gather 回复活动，以及它回的确认卡片 |
| `slack-negotiate.png` | Gather 私聊问"能不能调整"的消息，带 Yes / No 按钮（需要一个真人；也可以截虚拟参与者在帖子里的问答） |
| `slack-form.png` | 输入 `/gather` 后弹出的表单 |
| `slack-dm-create.png` | 私聊一句话发起活动后，Gather 给的预览，带 Post it / Edit first 按钮 |
| `dashboard.png` | 组织者网页面板（热力图和时间排名那一部分） |
| `slack-plan.png` | 点 Generate plan 后帖子里的方案（🥇🥈🥉 和底部按钮） |
| `slack-announce.png` | 点 Announce 后频道里的宣布消息 |

截图时注意不要截到真实的私人信息（比如别人的真名、私信内容）。用测试 workspace 和虚拟参与者最安全。
